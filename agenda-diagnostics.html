Agenda Tracker Diagnostics
A behind-the-scenes view of every background step that has to run for an agenda to be scraped, parsed, and attached to a jurisdiction — and matched to a Tracked Project. Each stage below reports its own health. Read the pipeline strip left-to-right: the first red or amber stage is usually where agendas stop flowing through.

This tool reads live data from the same Google Apps Script backend the dashboard uses (it reuses the connection you have already configured under Settings). It only reads — it never changes agenda, parse, or match data. Some checks call read-only operator ("admin_run") functions; if a stage shows "not authorized," the backend token isn't set for this deployment. Open the browser console for raw errors.
